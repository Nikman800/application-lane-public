# Screenshots

Screenshots used by the top-level README go in this folder. Take them with **synthetic data only** (an invented applicant and placeholder employers), never a real profile or real applications.

Needed (PNG, about 1280 px wide, light or a named theme):

| File | What it shows |
| --- | --- |
| `side-panel.png` | The side panel beside an application form, with two or three tracked applications, one filling, and the momentum card |
| `dashboard-profile.png` | The dashboard's **Your profile** page with the onboarding checklist and some confirmed facts |
| `find-jobs.png` | The **Find jobs** page with a few results |
| `progress-board.png` | The progress board on the **Submitted** page (streak, level track, heatmap, badges) |

Optional: `drafting-settings.png` (Settings → Drafting), `pairing.png` (the pairing-code prompt), `lane-ui.png` (the `npm run lane -- ui` terminal view in the Velocity theme).
